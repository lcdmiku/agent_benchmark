# Task: Create UTF-8 Special Character File

在当前工作目录 /app 中创建一个名为 special.txt 的文件。

要求：

1. 文件使用 UTF-8 编码。
2. 文件内容必须严格为以下四行：

第一行：你好，DSH！
第二行：双引号 "你好" 与单引号 '你好'
第三行：反斜杠 \ 和美元符号 $HOME
第四行：Emoji：🐳 🚀

3. 上述四行就是文件的全部内容，不要包含 Markdown 代码块标记。
4. 保留所有空格、标点、引号、反斜杠和大小写。
5. 文件末尾必须有且只有一个 LF 换行符。
6. 不要修改 tests 目录中的任何文件。
7. 创建后重新读取文件，验证内容。

完成后简要报告创建结果。
